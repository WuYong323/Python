## 0. 先跑起来

```python
# 05_syntax_sugar_demo.py

# ── 1. match 结构化模式匹配（3.10+） ──
def dispatch(cmd):
    match cmd:                          # 不是 switch！是"模式匹配"
        case {"op": "attention", "causal": bool(c)}:   # 解构 dict 并绑定
            return f"attention, causal={c}"
        case {"op": "ffn", "hidden": h} if h > 100:    # guard 子句
            return f"大 FFN, hidden={h}"
        case {"op": "ffn", "hidden": h}:
            return f"小 FFN, hidden={h}"
        case ("rmsnorm", w):            # 解构元组
            return f"rmsnorm weight shape={w}"
        case _:                         # 兜底
            return "unknown"

print(dispatch({"op": "attention", "causal": True}))   # attention, causal=True
print(dispatch({"op": "ffn", "hidden": 172}))          # 大 FFN, hidden=172
print(dispatch(("rmsnorm", (64,))))                    # rmsnorm weight shape=(64,)

# ── 2. 海象运算符 := （表达式里赋值） ──
# 旧写法：先读、再判空，循环里两处读
chunks = []
while True:
    chunk = read_chunk()               # 伪代码，见下真实例子
    if not chunk: break
    chunks.append(chunk)

# 新写法：赋值+判断一气呵成
lines = ["a", "b", ""]
out = []
while (line := lines.pop(0)):          # := 先赋值给 line，再判断真值
    out.append(line)
print(out)                             # ['a', 'b']

# 海象在"重复计算"场景救场：
import re
text = "loss=2.31 acc=0.91"
if (m := re.search(r"loss=([\d.]+)", text)):   # 一次匹配，结果复用
    loss = float(m.group(1))
print(loss)                             # 2.31

# ── 3. 解包（unpacking） ──
a, b = 1, 2                             # 元组解包
first, *rest, last = [1, 2, 3, 4, 5]    # * 吃掉中间
print(first, rest, last)                # 1 [2, 3, 4] 5

def f(*args, **kwargs):                 # 收集
    print("args:", args, "kwargs:", kwargs)
f(1, 2, name="x", lr=0.1)               # args: (1, 2) kwargs: {'name': 'x', 'lr': 0.1}

cfg = {"n_embd": 256, "n_layer": 4}
def g(n_embd, n_layer): return n_embd, n_layer
print(g(**cfg))                         # (256, 4)  ← ** 展开 dict 当关键字参数

# 多值解包（交换变量不用临时变量）
x, y = 1, 2
x, y = y, x
print(x, y)                             # 2 1

# ── 4. f-string 全谱 ──
name, val = "loss", 2.31415
print(f"{val=}")                        # val=2.31415  ← = 调试语法（3.8+）
print(f"{name}: {val:.2f}")             # loss: 2.31
print(f"{val:>10.3f}")                  # 右对齐占 10 宽：'     2.314'
print(f"{255:#x}")                      # 0xff
nested = {"a": {"b": 42}}
print(f"{nested['a']['b']}")            # 42（3.12+ 引号更自由）

# ── 5. 其他高频语法糖 ──
print(1 < 5 < 10)                       # True  ← 链式比较
for i, ch in enumerate("abc"):          # 同时拿索引和值
    print(i, ch)
print(any(x > 2 for x in [1, 3, 5]))    # True  ← 短路判断
print(all(x > 0 for x in [1, 3, 5]))    # True
```

运行：`python 05_syntax_sugar_demo.py`。

## 1. 一句话直觉

> **`match` 是"按形状拆快递"——不是比大小，而是看包裹长什么样、里面装了什么；海象 `:=` 是"边干边记"——在判断的同时把值记下来，省得再算一遍。**

类比：`match` 像海关安检的"形状识别"：不看具体值，而看结构——"这是带 causal 键的字典""这是三元组""这是列表头尾"。海象 `:=` 像"顺手拿个便签贴上去"——判断 `if chunk := get()` 的同时，已经把 `chunk` 记下了。

## 2. 核心原理

### 2.1 `match`：结构化模式匹配（不是 switch）

`match` 和 C/Java 的 `switch` 有本质区别：

| | switch | match |
|---|--------|-------|
| 比什么 | 值是否相等 | **结构**是否匹配（类型、形状、内容） |
| 能不能解构 | 不能 | 能（把 dict/元组/类的字段拆出来绑定） |
| 能不能加条件 | 不能 | 能（`case ... if guard`） |
| 匹配失败会贯穿吗 | 会 fall-through | 不会，命中即止 |

**核心能力：解构 + 绑定 + guard**：

```python
match cmd:
    case {"op": "attention", "causal": bool(c)}:   # ① 必须含 "op":"attention"
                                                   # ② "causal" 存在且绑定到 c
    case {"op": "ffn", "hidden": h} if h > 100:    # guard：额外条件
    case _:                                        # 兜底
```

**类的解构匹配**：

```python
@dataclass
class Point: x: int; y: int

def where(p):
    match p:
        case Point(0, 0):  return "原点"
        case Point(0, y):  return f"y 轴上, y={y}"
        case Point(x, 0):  return f"x 轴上, x={x}"
        case Point(x, y):  return f"({x}, {y})"
```

**何时用**：处理**有多种形状的消息/配置/命令**（如你的引擎将来要解析"请求协议"：不同请求带不同字段）。比一长串 `if isinstance(...) and key in ...` 清晰得多。

### 2.2 海象运算符 `:=`

`:=` 在**表达式**里做赋值，并返回赋的值。两大场景：

1. **`while` 循环"读+判"合并**：

```python
# 旧：读两次、易错
while (line := f.readline()):
    process(line)              # 读到 EOF 返回 ""，自动退出
```

2. **避免重复计算**：

```python
# 旧：算两次或写三行
if len(items) > 100:
    print(f"too many: {len(items)}")

# 新：算一次、记下来
if (n := len(items)) > 100:
    print(f"too many: {n}")
```

> **慎用**：`:=` 会让"赋值"藏进"判断"里，滥用会降低可读性。**只在"循环读流"和"重复计算"两处用**，别到处炫技。工业代码可读性 > 简短。

### 2.3 解包：`*` 的三种身份

`*` 在不同位置含义不同，但都是"展开/收集"：

```python
first, *rest = [1,2,3,4]      # ① 解包时 * = 收集剩下的
[*a, *b] = ...                # ② 多段解包
f(*args)                      # ③ 调用时 * = 展开可迭代对象
def f(*args): ...             # ④ 定义时 * = 收集为元组
```

`**` 同理作用于字典：调用时 `f(**cfg)` 展开成关键字参数；定义时 `def f(**kwargs)` 收集成字典。

**工业价值**：`g(**cfg)` 这种"dict 转关键字参数"在调模型、传配置时极常见。你的 `Config(**ckpt['model_args'])` 已经在用。

### 2.4 f-string 调试语法 `{x=}`

```python
f"{x=}"        # 展开成 "x=2.31415"（变量名+等号+值）
f"{x = :.2f}"  # "x = 2.31"（3.8+ 支持等号后加格式）
```

**调试利器**：插桩排查时，`print(f"{loss=} {logits=}")` 一行顶过去三行 `print("loss", loss)`。你的训练循环 `print(f"step {step:4d} | loss {loss.item():.4f}")` 已经用了一半，再加 `{device=}` 之类会更顺手。

## 3. 深入细节：三个易错点

### 坑 1：`match` 里的 `|` 是"或"，`_` 是通配

```python
match code:
    case 200 | 201 | 204:   # 或：任一命中
        return "ok"
    case _:                 # 通配：匹配任何东西（不是"任意变量名"）
        return "other"
```

注意 `_` 在 `match` 里是**通配符**，不是普通变量；而 `case x:` 是"匹配任何值并绑定到 x"。

### 坑 2：海象 `:=` 优先级低，复杂处要加括号

```python
if (n := len(items)) > 100:   # ✅ 括号明确边界
# if n := len(items) > 100:   # ❌ 会先算 len(items) > 100，n 变成 bool！
```

**记忆**：`:=` 优先级低于比较符，所以和比较符一起用时**必须加括号**。

### 坑 3：解包数量不匹配会抛异常

```python
a, b = [1, 2, 3]          # ValueError: too many values to unpack
a, *rest = [1]            # rest = []  ← * 可以吃掉 0 个，不会报错
```

**工业建议**：解包时对"数量不确定"的数据用 `*rest` 兜底，或先 `len()` 校验，避免线上 `ValueError`。

## 5. 自测题

**Q1（概念）**：`match` 和 `if/elif` 链都能做分支，什么情况下 `match` 明显更优？

**Q2（应用）**：写出下面需求的海象版：读文件直到出现空行，每读到非空行就存进 `lines`，并打印"当前共 N 行"。

**Q3（思考）**：`*rest` 解包和 `next(iter(...))` 在"取第一个元素"上有何不同？哪种对空列表更安全？

<details>
<summary>点击展开答案</summary>

**A1**：当需要**解构数据结构**（匹配 dict 的键、元组/类的字段并绑定变量）、**多个分支各有不同形状**、或需要 **guard 条件**时，`match` 明显更优——它把"判断 + 拆包 + 绑定"合成一行，避免一长串 `if isinstance(x, dict) and "op" in x and x["op"] == ...`。若只是简单值比较，`if/elif` 足够。

**A2**（示例）：
```python
lines = []
with open("f.txt") as fp:
    while (line := fp.readline().strip()):
        lines.append(line)
        print(f"当前共 {len(lines)} 行")
```

**A3**：`first, *rest = seq` 若 `seq` 为空会抛 `ValueError`（没有 first 可绑）；`next(iter(seq), default)` 可用第二参数给空序列一个默认值，更安全。所以"取第一个元素且可能为空"的场景用 `next(iter(seq), None)` 更稳妥；确认非空时才用解包。
</details>
